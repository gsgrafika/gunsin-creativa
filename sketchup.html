FAQ

Pertanyaan Umum

Apa saja data yang perlu saya kirim?

Minimal salah satu dari: denah 2D (gambar kerja), sketsa tangan, foto lokasi, atau referensi dari internet. Semakin lengkap, semakin akurat hasil render.

Bisa request revisi setelah jadi?

Tentu! Setiap paket memiliki kuota revisi. Revisi minor (warna, tekstur, sedikit pergeseran) biasanya dihitung lebih ringan dari revisi besar (ubah layout).

Apakah saya dapat file SketchUp-nya?

Untuk paket Premium, file `.skp` (SketchUp) disertakan. Untuk paket lain, bisa ditambahkan sebagai add-on sebesar Rp 200.000.

Bisa kirim ke luar kota?

Tentu! Kami sudah banyak mengerjakan proyek dari berbagai kota di Indonesia. Semua komunikasi dan pengiriman file dilakukan online.

Bagaimana kalau saya belum punya denah sama sekali?

Kami bisa bantu diskusikan konsepnya secara lisan/chat, lalu kami buat denah 3D-nya berdasarkan deskripsi dan referensi Anda. Ada biaya tambahan untuk konsultasi desain.

Berapa lama sampai hasil jadi?

Paket Basic: 3-4 hari. Standar: 4-5 hari. Premium: 7-10 hari. Waktu dihitung sejak data lengkap dan DP diterima.

Siap Lihat Rumah Anda dalam 3D?

Kirim denah atau referensi Anda, kami render jadi visual yang meyakinkan.
